# Recursos visuales

`campus_vista.png` es una ilustración generada para CampusGPS, con transparencia real. No representa un campus existente. Se usa en el estado inicial, no sustituye el mapa. El prompt completo está en campus_vista.prompt.json y dentro de los metadatos PNG.

Los SVG de iconos_svg/ se dibujaron para esta app. Sus equivalentes VectorDrawable están en app/src/main/res/drawable/. Comparten viewport 24, trazo 1.8 y extremos redondeados. No se usan emojis como iconos.
